# Security policy

## Reporting a vulnerability

Report it privately through [GitHub security advisories](https://github.com/Crocogiciel-Studio/sandy/security/advisories/new). Do not open a public issue.

Include the affected version, the steps to reproduce, and the impact. You will get an answer as soon as possible.

## Scope

sandy drives `sbx` and embeds terminals. Reports about the Electron configuration (context isolation, sandbox, IPC surface) or about how sandy passes paths and commands to `sbx` are in scope. Vulnerabilities in `sbx` itself belong to Docker.

## Supported versions

Only the latest release is supported.
